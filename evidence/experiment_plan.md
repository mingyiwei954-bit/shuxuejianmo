# C题预注册实验计划

版本：paper-agent-v1  
状态：结构已冻结，数值待统一流水线写入  
正式评估区间：2025-02-01 00:00 至 2025-12-31 24:00，共 334 天  
训练与参数选择区间：2025-01-01 至 2025-01-31，不进入正式费用比较

## 1 实验目的

实验回答五个可检验问题。

1. 仅使用决策时刻以前信息的日前策略是否可完整执行，并在 334 天内保持能量平衡和 SOC 可行？
2. 24 h 跨日预测窗口与终端状态处理是否改善费用或减少紧急购电？
3. 按发布时间和提前期进行光伏偏差校正是否改善真实执行结果？
4. 使用完整历史残差轨迹的两阶段场景滚动是否优于同口径确定性策略？
5. 0、6、12、18 时的更新频率 S0-S3 对费用的边际影响是否超过数值误差和历史日序列波动？

实验不以完全信息结果作为正式策略。完全信息模型仅用于同约束、同日期、同 SOC 端点下的事后参照。

## 2 冻结数据与信息边界

### 2.1 时间和端点

- 内部十分钟时段使用右端点解释：附件中的 `00:10` 对应物理区间 `[00:00,00:10)`。
- 官方工作簿标签原样保留，映射表同时保存 `source_timestamp`、`physical_interval` 和 `official_template_label`。
- 2025-02-01 00:00 SOC 固定为 6000 kWh。
- 2025-12-31 24:00 SOC 强制为 6000 kWh。
- 跨日 SOC 连续，不承接 1 月某一策略产生的状态。

### 2.2 可见信息

在日期 `d`、决策时刻 `tau`：

- 负载预测只读取 `d` 以前最近四个同星期日的完整实际曲线；
- Q4 电价预测采用相同历史规则；
- 光伏预报只读取附件 3 中发布时间不晚于 `d,tau` 的版本；
- 已发生实际负载、光伏和价格可用于更新当前 SOC 和结算；
- 尚未发生的实际量禁止进入预测器和规划器；
- 任何历史样本日期必须严格早于其所服务的决策日期。

每次决策必须在 `decision_version` 留下：决策时刻、预报发布时间、有效时段、历史截止日、历史来源日期、旧承诺、新承诺、决策初始 SOC、求解器状态和配置哈希。

## 3 共同物理与费用口径

单段长度 `Delta t=1/6 h`。核心变量均以 kWh 计：计划购电 `B_t`、最终承诺 `A_t`、紧急购电 `Q_t`、充电 `C_t`、放电 `D_t`、未用能量 `W_t`、段末储电量 `E_t`。

共同约束：

```text
A_t + Q_t + G_t*Delta t + D_t = L_t*Delta t + C_t + W_t
E_t = E_(t-1) + 0.9*C_t - D_t/0.9
1200 <= E_t <= 10800
0 <= C_t,D_t <= 5000/6
B_t,A_t,Q_t,W_t >= 0
```

规划阶段用当时的预测量，执行阶段用实际量形成 `Q_t` 和 `W_t`。全精度记录是费用和工作簿的唯一源。

Q3/Q4-3 主结算按最终承诺相对 0 点计划：

```text
cost_t = p_t*min(B_t,A_t)
       + 0.5*p_t*max(B_t-A_t,0)
       + 1.5*p_t*max(A_t-B_t,0)
       + 5*p_t*Q_t
```

同一决策链还要按相邻版本逐次结算，作为敏感性结果。二者不得混入同一主费用列。

## 4 一月参数选择

参数选择使用逐日滚动原点。每一天的模型只读取该日以前的数据；若所需历史不足，则使用当时全部可用的同星期日/同发布时间样本并记录实际样本数。不得为了补齐四周或 20 个场景读取 2 月以后的数据。

### 4.1 终端规则候选

| 编号 | 规则 | 定义 |
|---|---|---|
| T0 | 每日闭环基线 | 每天 24:00 SOC 等于当天 0:00 SOC |
| T1 | 24 h 首尾相同 | 每次滚动窗口末端 SOC 等于该次决策初始 SOC |
| T2a | 软目标 0.5 | 窗口末端偏离 6000 kWh 的绝对值乘 `0.5*median(predicted_price)` |
| T2b | 软目标 1.0 | 同上，系数为 1.0 倍 |
| T2c | 软目标 1.5 | 同上，系数为 1.5 倍 |

选择准则按优先级执行：

1. 所有日和所有重规划均可行；
2. 无 SOC、功率、能量平衡和信息边界违例；
3. 一月真实执行总费用最低；
4. 若总费用分币相同，依次选择紧急购电更少、终端偏差更小、系数更简单者。

选定后写入 `config/final.yaml`，2-12 月不得再调参。

### 4.2 固定增强参数

- 偏差均值窗口：过去 28 天。
- 异常上界窗口：过去 60 天相同时钟小时实际光伏的 99.5% 分位数。
- 历史残差场景：相同发布时间的最近最多 20 条完整轨迹。
- 场景概率：等概率。
- 第一阶段：当前至下一重规划时刻，共 6 h；所有场景决策一致。
- 后续阶段：允许场景递补。
- 官方模板要求 0 点给出当天完整计划。场景模型的后续分支不能冒充已承诺的全日计划，因此 0 点另用同一校正点预测求一次确定性计划填充当日剩余时段；场景模型只替换首个 6 h 的共同决策。未来场景分支保留为递补证据，不写入正式承诺。
- 风险项：无。
- 正式不确定性区间：7 天移动块自助法，重复次数由配置冻结；建议不少于 2000 次，随机种子写入配置。

## 5 六组消融实验

六组在 Q3 固定电价和 Q4-3 波动电价下分别运行。除表中组件外，预测窗口、更新时刻、物理约束、费用、评估日期和 SOC 端点完全一致。

| 组别 | 原始光伏预报 | 偏差校正 | 跨日终端 | 残差场景 | 用途 |
|---|---:|---:|---:|---:|---|
| A0 原始预测基线 | 是 | 否 | 否，采用每日闭环 | 否 | 因果滚动基线 |
| A1 仅跨日终端 | 是 | 否 | 是，采用一月选中规则 | 否 | 隔离跨日终端贡献 |
| A2 仅偏差校正 | 否 | 是 | 否，采用每日闭环 | 否 | 隔离偏差校正贡献 |
| A3 偏差校正加跨日 | 否 | 是 | 是 | 否 | 检查两个确定性增强的组合 |
| A4 场景滚动加跨日 | 是 | 否 | 是 | 是 | 隔离场景处理贡献，不混入偏差校正 |
| A5 三项组合 | 否 | 是 | 是 | 是 | 正式 Q3/Q4-3 候选主模型 |

“原始预报”与“偏差校正”互斥。A4 的场景残差以原始预报为基准，A5 的场景残差须明确以校正后预报还是原始预报定义，并在冻结配置中只选一种。建议定义为 `actual - corrected_forecast`，避免均值偏差在场景中重复出现。

## 6 S0-S3 更新频率实验

只对选定的 A5 组合模型执行：

| 策略 | 正式重规划时刻 | 可修改范围 |
|---|---|---|
| S0 | 0:00 | 当天 144 段形成 0 点正式计划；下一日仅预览 |
| S1 | 0:00、6:00 | 6 点只调整当天尚未发生段 |
| S2 | 0:00、6:00、12:00 | 12 点只调整当天尚未发生段 |
| S3 | 0:00、6:00、12:00、18:00 | 18 点只调整当天尚未发生段 |

24 h 窗口跨过午夜时，下一日购电计划在午夜前不形成正式承诺。预览变量可以影响当前储能决策，但不得写入下一日的旧承诺字段；下一日 0 点必须基于当时信息重新形成正式计划。

每个模式、组别、S 策略至少输出下列指标：

| 费用 | 总费用、正常计划费用、下调违约费、上调费用、紧急购电费、逐次交易总费用 |
| 能量 | 计划购电量、最终承诺购电量、紧急购电量、未用能量、充电量、放电量、储能损耗 |

| 终端 | 初始 SOC、最终 SOC、相邻日不连续最大值、窗口末端偏差分布 |

## 8 求解器稳定性实验

S2 和 S3 在 Q3、Q4-3 下分别用以下组合复算：

- 方法：HiGHS 自动、HiGHS-DS、HiGHS-IPM；
- 充放电并列破除系数：`epsilon_low`、`epsilon_mid`、`epsilon_high`，具体值从配置读取；
- 主费用中剔除并列破除项，只用它选择退化解；
- 每次保存全精度目标、报告目标、状态、迭代数、原始/对偶残差和解哈希。

判定：

1. 任一组合不可行或未达最优，S2/S3 稳定性不通过；
2. 若 `S3-S2` 的方向在组合间变化，写“数值不可区分”；
3. 若方向一致但四舍五入到 0.01 元的差值不一致，仍写“数值不可区分”；
4. 只有方向和分币结果全部一致，才能报告稳定的边际费用差；
5. 无论差异是否稳定，都不能推广成“18 点预报一般没有价值”。结论仅限本题数据、模型、窗口和结算口径。

## 9 统计区间

对每个对比构造逐日费用差 `delta_d`。从 334 天序列中建立所有连续 7 天块，带回放抽取块并拼接到 334 天，截断多余天数；每次计算全年差值总和。95% 区间取重采样总和的 2.5% 和 97.5% 分位数。

必须同时输出：

- 点估计 `sum(delta_d)`；
- 7 天移动块区间；
- 12 个自然月的费用差；
- 正费用天数、负费用天数和零差天数；
- 块长度为 1、7、14 天的敏感性表，主结论仍以预注册的 7 天为准。

若区间跨 0，论文不得写“显著降低”；应写“点估计为节省/增加，但历史块重采样区间跨 0”。

## 11 验收门

### G1 输入与时间

- 附件 1：1 天 × 144 个唯一时段；附件 2、4：365 天 × 144 个唯一时段；附件 3：365 天 × 4 个发布时间。
- 无空值、非数值和公式错误；不允许静默补零。
- 正式结果覆盖 334 天，每天 144 个唯一时段且顺序一致。

### G2 因果与承诺

- 历史日期早于决策日；预报发布时间不晚于决策时刻。
- 已发生时段不可改写。
- 下一日预览不进入正式承诺链。
- `previous_commitment` 与上一版本完全一致。

### G3 物理与费用

- 所有 LP 可行并达到配置规定容差。
- SOC 跨日连续，起点和终点均为 6000 kWh。
- 全量逐段重算平衡、状态转移和费用。
- 紧急购电连续区间由全精度 `Q_t` 重建，只省略四位显示后为 0 的记录。

### G4 结果一致性

- 图、表、论文、五份工作簿只读同一冻结清单和全精度明细。
- 指定日期和四小时汇总从明细自动聚合。
- 新版正式结果零 FAIL；旧成果的 FAIL 和不可验证项继续单列。

### G5 论文措辞

- 因果策略为正式主结果，完全信息只作参照。
- 不用“理论下界”描述不满足同目标、同可行域和信息包含条件的结果。
- 不用“显著”“稳健”“无价值”等词超出统计和求解器证据。
