# C题论文格式与匿名提交检查表

版本：paper-agent-v1  
官方依据：[全国大学生数学建模竞赛论文格式规范（2026年修订稿）](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html)；[人工智能工具使用规定（2026年试行）](https://www.mcm.edu.cn/html_cn/node/fef94648f2836ab6cc81586f4c38512b.html)

本表分为自动检查和人工确认。自动检查通过不等于可以提交，最终必须逐页、逐表、逐文件人工复核。

## 论文内容顺序

- [ ] 电子论文第一页是摘要专用页。
- [ ] 电子论文不含承诺书。
- [ ] 电子论文不含编号专用页。
- [ ] 摘要含论文标题、摘要正文和关键词，原则上不超过一页。
- [ ] 摘要页页码为 1，位于页脚中部。
- [ ] 正文从电子论文第二页开始，页码连续。
- [ ] 不设置目录。
- [ ] 正文部分不超过 30 页；单独记录正文起止页，不能只看整份 PDF 总页数。
- [ ] “AI工具使用声明”位于参考文献之前。
- [ ] 参考文献之后为附录。
- [ ] 附录列出支撑材料文件清单。
- [ ] 附录包含全部完整、可运行源程序，或明确指向支撑材料中对应的完整代码文件及运行命令。

## 页面和排版

- [ ] 纸张为 A4。
- [ ] 上下左右页边距均不小于 2.5 cm。
- [ ] 正文、图、表和公式均保持在页边距以内。
- [ ] 页码位于页脚中部，阿拉伯数字连续，无重复和跳号。
- [ ] 标题和各级标题为黑色，无装饰线、边框或彩色主题残留。
- [ ] 中文和英文字符均正确显示，无方框、乱码或字体替换导致的错位。
- [ ] 公式完整，无裁切、断裂、基线错位或原始 LaTeX 文本残留。
- [ ] 表格列宽合理，表头重复，单位写入表头，数字小数位一致。
- [ ] 图中文字在 100% 缩放下清晰，坐标轴、图例和单位完整。
- [ ] 图题置于图下，表题置于表上，编号连续且正文均有引用。
- [ ] 没有因表格或图片推页产生大面积异常空白。
- [ ] 参考文献编号与正文引用一一对应。

### 建议正文页数预算

该预算不是官方强制格式，只用于把正文稳定控制在 30 页以内。摘要单独占 1 页，附录页数另计。

| 内容 | 建议页数 |
|---|---:|
| 问题重述、分析、假设和符号 | 3 |
| 问题一模型与结果 | 3 |
| 问题二预测、模型与结果 | 4 |
| 问题三滚动、校正、场景和结果 | 7 |
| 问题四模型与结果 | 4 |
| 消融、统计区间、敏感性和审计 | 5 |
| 模型评价与结论 | 2 |
| AI声明与参考文献 | 2 |
| 合计 | 30 |

当页面超限时，优先把大篇幅指定日期明细、完整稳定性表和程序清单移到附录或支撑材料；不得通过把正文缩到难以阅读的字号来满足页数。

## 论文数值一致性

- [ ] 所有 `{{RESULT:...}}` 占位符已经替换，搜索结果为零。
- [ ] 摘要中的费用、节省、区间和审计数量与正文一致。
- [ ] 正文表 1、表 2、表 3 的指定时段与五份工作簿一致。
- [ ] 2025-03-20、06-21、09-23、12-21 的日期、紧急购电区间和总量一致。
- [ ] 所有四小时充放电汇总来自相同的 10 min 全精度明细。
- [ ] Q3/Q4-3 的主费用明确标为最终相对 0 点计划结算。
- [ ] 逐次交易费用单列，没有与主费用相加或混称。
- [ ] 因果策略为正式主结果；完全信息结果明确标为事后对照。
- [ ] 6000 kWh 起点、6000 kWh 终点和 334 天范围在摘要、方法和结果中一致。
- [ ] S2/S3 若不稳定到分币，正文和摘要均写“数值不可区分”。

## AI工具规则

- [ ] 论文参考文献前存在以下声明，且用途与事实一致：

```text
本参赛队在竞赛过程中使用了AI工具，主要用于文献检索辅助、代码调试、审计检查和语言润色，详细使用情况见支撑材料。
```

- [ ] 支撑材料中存在文件名完全为 `AI工具使用详情.pdf` 的文件。
- [ ] AI 详情列出所有实际使用的 AI 工具，而不是只列本次会话。
- [ ] 每个工具填写名称、版本或型号；无法取得型号时如实说明并保留核查证据。
- [ ] 记录具体使用目的和环节。
- [ ] 记录主要提示方式、使用过程和代表性交互。
- [ ] 对语言润色以外的 AI 输出，记录采纳、人工修改和核验。
- [ ] 团队已经人工审查核心模型、程序、结果和引用。
- [ ] AI 详情中没有尚未替换的占位符、内部指令或虚构的人工签名。

## 匿名内容检查

以下检查覆盖论文、五份工作簿、支撑材料 ZIP 内全部文件、图表、日志和元数据。

- [ ] 不出现队员姓名、指导教师姓名、学校、学院、赛区、队号或学号。
- [ ] 不出现个人邮箱、电话号码、即时通信账号、云盘账号或用户名。
- [ ] 不出现任何带本机用户名的 macOS 或 Windows 绝对用户目录路径。
- [ ] 不出现 Git 作者姓名和邮箱。
- [ ] 不出现 Office 文档属性中的 Creator、Last modified by、Company、Manager。
- [ ] 不出现批注作者、修订作者、隐藏批注或未接受的修订。
- [ ] 不出现图片 EXIF 作者、GPS 或设备所有者信息。
- [ ] 不出现工作簿隐藏表、定义名称、外部链接、连接字符串中的身份信息。
- [ ] 不出现脚本日志中的账户名、主机名、缓存路径或访问令牌。
- [ ] 不包含 API 密钥、Cookie、访问令牌、私有仓库地址或 `.env` 文件。
- [ ] AI 会话证据若含身份或账号信息，先脱敏再进入支撑材料。

建议的自动文本扫描词表由团队在不进入提交包的私有文件中维护，包括队员姓名、学校全称/简称、邮箱用户名、本机用户名、主机名和队号。匿名扫描程序只输出命中位置和摘要，不把私有词表打包。

## 文档元数据检查

### DOCX

- [ ] 清除核心属性中的作者、最后修改者、公司和管理者。
- [ ] 删除批注、批注关系和批注作者。
- [ ] 接受或拒绝所有修订，最终版不存在跟踪修订标记。
- [ ] 清除自定义属性、隐藏文本和文档变量中的身份内容。
- [ ] 重新打开最终 DOCX，确认标题、作者字段和页码正常。

### PDF

- [ ] PDF Title 可以保留匿名论文题名。
- [ ] PDF Author、Creator、Producer 中不含个人、学校或本机用户名；软件通用名称可保留。
- [ ] PDF 附件、批注、表单、JavaScript 和隐藏图层均按预期，不含额外文件。
- [ ] 文本提取后再次运行匿名词扫描。

### XLSX

- [ ] `docProps/core.xml` 和 `docProps/app.xml` 不含个人或学校信息。
- [ ] 所有批注、人员信息和外部连接已删除或确认必要且匿名。
- [ ] 工作表名称与官方模板一致。
- [ ] 没有意外隐藏工作表或 veryHidden 工作表。

## 文件与大小

- [ ] 正式论文选择一个单独 PDF 文件提交，不压缩。
- [ ] 正式论文 PDF 小于 20 MB。
- [ ] 可编辑 DOCX 作为工作成果保留；若平台只要求一个论文文件，不同时上传 PDF 和 DOCX。
- [ ] 支撑材料使用一个 ZIP 或 RAR 文件。
- [ ] 支撑材料压缩包小于 20 MB。
- [ ] 压缩包不含承诺书和编号专用页。
- [ ] 压缩包不含赛题已经提供的原始数据附件，除非提交说明明确需要。
- [ ] 大型重复 CSV 不进入压缩包；保留代码、配置、压缩全精度结果、必要日志、图表数据、五份结果表和 AI 详情。
- [ ] 压缩包解压后无多余顶层目录层级、系统隐藏文件、临时文件和缓存。
- [ ] 删除 `.DS_Store`、`__MACOSX`、`__pycache__`、`.pytest_cache`、锁文件和编辑器备份。
- [ ] 文件名只使用常见中文、英文、数字、下划线和连字符，避免跨平台非法字符。

## 支撑材料完整性

- [ ] `run_pipeline.sh` 存在且可执行。
- [ ] `config/final.yaml` 存在，包含全部关键参数和随机种子。
- [ ] README 给出从原始附件重建全部成果的一条命令。
- [ ] 代码不依赖未记录的绝对路径。
- [ ] 依赖版本和运行环境记录完整。
- [ ] 冻结结果清单及其 SHA-256 存在。
- [ ] 人读审计报告和机器审计 JSON 存在。
- [ ] 文献证据和实验计划存在。
- [ ] 五份 `result*.xlsx` 存在并通过独立审计。
- [ ] 论文附录中的文件清单与压缩包实际内容逐项一致。
- [ ] 在一个全新临时目录解压后，按 README 完整复跑成功。

## 五份工作簿检查

每份工作簿均执行以下检查。

- [ ] 工作表名称、顺序、表头、合并单元格和布局与官方模板一致。
- [ ] 结果 2、3、4-2、4-3 覆盖 334 天，每天 144 个唯一时段。
- [ ] 公式重新计算后没有 `#REF!`、`#VALUE!`、`#DIV/0!`、`#NAME?`、`#N/A` 等错误。
- [ ] 不存在把空单元格静默解释为 0 的审计路径。
- [ ] 数字显示四位小数，但来源为全精度冻结结果。
- [ ] 日期和时间格式在 Excel 与 LibreOffice 渲染中一致。
- [ ] 列宽、行高、分页和打印区域无截断或错位。
- [ ] 紧急购电连续区间由全精度逐段值重建，只省略四位显示为 0 的记录。
- [ ] 重新打开工作簿后公式值、日期、工作表可见性和外部链接状态正常。

## 逐页视觉检查

### DOCX和论文PDF

- [ ] 用指定文档渲染器把最终 DOCX 转为逐页 PNG，并查看每一页。
- [ ] 用 Poppler 把最终 PDF 转为逐页 PNG，并查看每一页。
- [ ] 两套渲染页数和主要分页一致。
- [ ] 100% 缩放下没有裁切、重叠、乱码、黑方块和低清图。
- [ ] 摘要确实在一页内。
- [ ] 正文页数单独计数不超过 30。
- [ ] AI 声明完整位于参考文献前。
- [ ] 附录起始位置和文件清单清晰。

### 工作簿

- [ ] 每个工作表均渲染为 PDF 或图像查看，不只检查单元格值。
- [ ] 超宽表的冻结窗格、打印缩放和标题行可读。
- [ ] 指定日期和紧急购电表没有因行高不足而隐藏记录。
