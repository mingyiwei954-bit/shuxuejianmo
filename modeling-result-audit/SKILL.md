# 建模结果独立复核与讨论

将原题、数据、信息可用时刻、代码、运行配置、逐步结果、导出表、论文结论连接起来，检查“算得对、模型符合题意、结论由结果支持”三个不同层次。求解成功、文件存在或原项目的PASS不能互相替代。

## 范围与版本

- 用户只要求“看结果、讨论、复核”时，以只读审查为默认；在独立工作目录保存快照和审查产物。已有明确修复授权时继续该范围内的修改，无需重新请求相同授权。
- 若另一AI正在制作，记录快照时间、文件清单和关键哈希。源稿、PDF、配置、冻结数据可能来自不同轮次，分别认定；将未同步列为状态，不直接当作最终作品缺陷。
- 不运行未审阅且会覆盖原文件的流水线。先确定其读写路径及本次任务是否需要重算。
- 其他环境无法访问本地路径时，使用上传的技能包及项目材料；说明无法读取的证据，不声称已经核查。允许继续不依赖缺失文件的工作。

## 审查入口

普通项目先从论文核心结果反向追踪。只有审查2026 C题或本次V3修订时，才读[案例证据与复现方法](references/c2026-evidence-chain.md)，并按需要读其中链接的两份历史报告。历史数值是待复现线索，不是未来版本必须匹配的标准答案。

## 建立可复算证据链

对每项影响结论的指标，定位：

`原题条款/原数据 → 时间及单位映射 → 决策时可用输入 → 代码函数与实际运行配置 → 逐时段轨迹/承诺版本 → 汇总及工作簿位置 → 论文页码、表格和结论`

重点区分当前源码与生成结果时的源码/配置，声明的策略与导出表实际承载的策略。哈希相同只能说明文件一致，不能说明数学正确。

每条发现写出具体触发条件、文件/函数/行号或页码/单元格、原值、独立复算方法、复算值、差额、影响和修复后的验证方法。找不到某一环时标记“尚不可验证”，不要补造证据。

## 独立检查

1. **数据及时间：**核对功率/电量、时间戳与区间起止、跨日、缺失与真实零、正式评价范围。论文抽取按物理区间，导出按已说明的模板映射；不能因为总量一致就认定时序一致。
2. **因果边界：**比较观测完成、预报发布、特征计算与决策时间。历史日期早于决策日仍不足以证明一条跨日残差轨迹已经完整观测。需要时扰动未可用的未来实际数据，在固定随机种子下检查早期决策是否改变；只在隔离副本上实施。
3. **物理可行性：**从原数据与逐步动作独立重算守恒、状态递推、边界、相邻状态衔接和互斥行为。汇总表无法替代逐时段检查；已舍入值与全精度值使用不同容差。
4. **费用：**先用小例子验证单位、增减量、倍率及退费解释，再从承诺链逐次重算。研究“同一路径换结算规则”时保持实际路径一致；研究另一策略时，重新计算该策略自己的缺口、状态和费用。不要混用假设采购路径与另一条路径的紧急购电费。
5. **决策质量：**检查实际惩罚是否进入规划，而非只在运行后统计。设计少量透明的可行基线，例如固定余量、保持原计划、无储能；除被比较因素外保持条件一致。诊断用历史回放不能被包装成样本外收益；最终调参须遵守时间切分。
6. **实验与结论：**同名模型不保证公平比较。检查日前承诺、预测、随机场景共同决策范围、终端条件、求解器及结算是否同时改变。只有受控实验支持模块归因。更小的可行域残差不代表更高经济价值；并列最优解的执行差异也不是“几位小数”的问题。
7. **论文与交付：**核对关键数字、指定时段、策略名称、图表和主结论。先找会改变结论的错误，再处理文字和版式。若获得评分器，要求每项扣分有评分规则及作品位置；没有评分记录就不推断真实扣分来源或奖项。

优先复算关键账本和一个有区分力的基线。仅在现有证据不足以回答问题或用户要求时扩大重跑范围，避免为了增加检查数量重复全部实验。

## 区分发现的性质

- **已证实错误：**原数据、代码和独立计算直接支持，足以指出具体失配。
- **明确的模型局限：**现有假设或策略可行，但没有处理某项重要风险，或被简单基线改善。
- **合理但待验证的解释：**代码存在可能原因，尚未用受控实验确定贡献。
- **版本待同步：**制作中的源稿、表格和PDF不同步，需要最终冻结后复验。
- **未发现证据：**例如未见隐藏提示词，不等同于证明所有“反AI机制”不存在。

对有多种合理解释的题意，列出假设及影响，不能把自己的解释冒充官方答案。相关文献支持一般机制，不证明本题出题动机或当前团队错误。

## 讨论与交付

开头先说明哪些结果可信、最影响结论的是什么及审查范围。重点讨论3—5项有证据的发现，用具体金额、时段、约束或实验差异解释影响。将完整证据链放入可访问的报告，给出链接。

不要把“有AI痕迹”“模型不够高级”“还需要加强验证”等泛泛评语当作诊断。改进建议必须对应已发现问题和可检验的完成条件。

已获修复授权时，执行“复现问题 → 修改相关模型或提取逻辑 → 重算受影响结果 → 独立复验 → 同步导出和论文”，保留修订前后差异及配置来源。只有正文改名、补充解释或修改PASS标记，不能宣称数值问题已经修复。
