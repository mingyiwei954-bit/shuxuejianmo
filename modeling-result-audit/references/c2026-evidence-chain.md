## 1. 问题二、四-2的风险成本

链路：题目问题二5倍紧急购电价 → `src/model/experiments.py:simulate_day_ahead` → `src/model/lp.py:solve_deterministic` → `frozen/q2_dispatch.csv.xz`及`q4_2_dispatch.csv.xz` → 工作簿及论文费用。

旧版本只在执行后计算紧急购电罚款。复验应先确认当前代码是否已经把随机缺口成本、分位数或其他有根据的余量放进规划。

可重用的诊断：保持储能动作不变，把原计划每时段增加固定δ，在允许不利用富余电量且没有额外购电上限时，独立计算 `Q'=max(Q-δ,0)` 与 `Σp(B+δ)+5pQ'`。更一般地从原负载、光伏和动作重算缺口，避免原Q字段已经错误。

旧快照δ=20 kWh/10分钟时，Q2节省740,311.13元，Q4-2节省813,777.27元。这是历史诊断，不是推荐新版本必须采用20，也不证明泛化效果。先验选择、训练期调参和正式期评价必须分开。

## 2. 逐次结算路径

链路：题目与论文结算定义 → `rolling.py` 中 `sol.grid`、`backup.grid`、`sensitivity_proposal`、`sequential_delta` → `decision_versions.csv.xz` → 正式执行明细与紧急购电 → PDF第9—11页比较（旧页码）。

原实现用确定性补全路径计算逐次调整，用随机执行路径计算紧急购电。需要按模式、目标日期、交付位置、决策时间重建正式承诺，排除次日预览和非正式场景递补；与逐段实际执行量核对。

旧快照从正式链重算：Q3为16,662,138.66元，Q4-3为17,539,062.52元，分别比原逐次费用高204,566.66和201,870.19元。

在该项目当前退费解释、相同路径且每个交付时段的各次调整采用相同p≥0时，单次变化x的费用 `f(x)=px+0.5p|x|`，因此 `Σf(Δ)-f(ΣΔ)≥0`。逐次调整不得比同一最终净变化便宜。如果价格口径改为每次交易时的不同价格，或路径/紧急购电改变，这条比较不能直接套用。

## 3. 论文时间标签

链路：原始时刻00:10…24:00 → 内部 `physical_interval` → 导出 `official_label` → 论文指定时段提取逻辑。

旧PDF第17页表8将486.4029 kWh标为12:00—12:10，但它对应冻结物理区间11:50—12:00；真实12:00—12:10为480.41245。新版本应逐个指定区间按物理键重取，再核对模板位置及聚合规则；不能仅验证全天合计。

## 4. S0/S3受控比较

链路：`experiments.schedules` → `rolling.py:simulate` 的 `execute` → 0点 `baseline` 由随机首块覆盖确定性全天补全 → 场景共同变量覆盖范围 → `experiment_summary.csv.xz` → 策略结论。

旧S0首块为全天，旧S3首块为6小时，故日前风险处理范围不同。旧固定电价S3减S0：计划费−935,610.48元，调整费+727,140.24元，紧急费+392,510.90元，总额+184,040.66元。

这能证明比较混入其他因素，不能单独证明贵出的全部金额由补全方式导致。修复后固定共同日前计划做更新价值实验，或明确比较的是不同完整策略。
