## 恢复与复算

1. 解压支撑材料.zip。原题及附件按来源记录另行准备，设置CUMCM_SOURCE_ROOT为其父目录（该目录下有C题/附件），或修改config/final.yaml的source_root。
2. 安装requirements.txt中的Python依赖，在支撑目录执行 python scripts/unpack_frozen.py。56份CSV按原始字节恢复，包含补充实验轨迹；原始数据没有改写或舍入。
3. 执行 python src/audit/audit_final.py --workbooks，直接从原题附件复算正式轨迹、真实承诺链和五份表格。执行 python scripts/strengthen_evidence.py 可对恢复的四组补充轨迹重新核算；如需重跑其优化过程，先在备份后移走research目录内对应缓存文件。
4. 完整重建入口为run_pipeline.sh；工作簿生成额外需要Node与@oai/artifact-tool，DOCX/PDF生成使用包内所声明的文档运行时。独立数值核验仅需要Python。

final_validation_v3.json记录工程内部的文档路径；本交付目录以SHA256SUMS_v3.json为实际文件清单。最终交付复验.json来自本轮压缩包解压后的重新检查，而非复制旧PASS。
